## 참고 (부채는 아니지만 알려진 제약)
- 이 버전이 내보내는 JSON(ImageSpec 0.3.0)은 Sprint 0·1·2-A 앱이 읽지 못합니다(ADR-028, ADR-038).
- 국가·지역 프롬프트 표현(형용사)은 외부 데이터셋 없이 작성했습니다(ADR-045). 실제 사용에서 어색한 표현이 발견되면 카탈로그 버전을 올려 개선합니다.
- 연령 판단은 사용자가 입력한 구조화 값만 근거로 하며 이미지 내용은 판단하지 못합니다(ADR-042).
- 로컬 안전 정책은 키워드 기반 기준선입니다(ADR-019).
- 이 개발 환경의 명령 sandbox에서는 Playwright Chromium이 시작되지 않습니다. CI와 일반 개발 환경에는 해당하지 않습니다.
