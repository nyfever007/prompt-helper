# 안전 정책 — `prompter.baseline`

- 현재 버전: **0.3.0** (Sprint 2-C.3, ADR-065). 이전 버전: 0.2.0(Sprint 2-B.1), 0.1.0(Sprint 1)
- 구현: `src/domain/safety/baselinePolicy.ts`(신호·규칙), `evaluate.ts`(평가), 컴파일러의 안전 입력(`src/domain/compiler/compiler.ts`)
- 결정 기록: ADR-019(정책 계층·한계), ADR-042(연령 판단), ADR-044(0.2.0), ADR-053(내의), **ADR-065**(0.3.0)

이 정책은 **로컬 규칙 기반(키워드와 구조화 태그) 기준선**입니다. 의미를 이해하는 콘텐츠 분류기가 아닙니다.
- 바꿔 말한 표현, 속어, 오타, 다른 언어, 이미지 내용은 놓칠 수 있습니다.
- 정상 표현을 잘못 걸러낼 수도 있습니다.
- 외부 이미지 생성 모델의 정책을 통과한다고 보장하지 않습니다.

## 1. 원칙

- 일반적인 외모·신체·의상·자세의 비성적 묘사는 성적 대상화와 구분합니다.
- 미성년자의 성적 대상화를 막습니다. 연령 정보가 충돌하면 미성년자 쪽을 우선합니다.
- **연령 불명은 성인으로 간주하지 않습니다**(0.3.0).
- 노골적인 성적 콘텐츠와 나체는 연령과 관계없이 차단합니다(변경 없음).
- 저장된 원본 값은 바꾸지 않습니다. 정책을 피하려고 표현을 바꾸지도 않습니다.
- 프롬프트에서 제외한 값, 현재 적용되지 않는 값, 사용자 정의 이름과 표현, 선택된 모든 선택지의 태그, 구조화 연령 신호, 어댑터가 만든 최종 문장을 **모두** 검사합니다.
- 일반적인 충돌 진단(카탈로그 규칙, TD-10)과 안전 차단은 서로 별개입니다.
- 남성과 여성에게 같은 원칙을 적용합니다. 결과는 성별에 따라 달라지지 않습니다(테스트로 확인).

## 2. 신호

| 신호 | 근거 | 비고 |
|---|---|---|
| `age.minor` | 연령대(미성년 구간), 실제·외형적 연령 < 18, 어휘(child, teen, 초등학생 …) | 구조화 신호와 어휘 |
| `age.ambiguous_young` | 18세 경계를 걸친 연령 범위, “앳된” 인상, 어휘(girl, boy, 교복, 소녀 …) | |
| `age.adult_confirmed` (0.3.0) | **구조화 연령 판단 결과가 성인일 때만**: 연령대, 외형적 연령, 실제 연령(인간인 경우만) | 어휘 없음. 자유 입력의 “adult”·“25세”로는 확인되지 않습니다 |
| `appeal.sexualized` | 어휘(sexy, seductive, sensual, lingerie, boudoir, 섹시, 관능 …), 태그 `appeal.suggestive` | 0.3.0: underwear·panties·bra·속옷·팬티·브래지어는 제외(아래 `garment.intimate`로 이동) |
| `garment.intimate` (0.3.0) | 속옷류 의복 분류: 어휘(underwear, bra, briefs, boxer shorts/briefs, panties, shapewear, lingerie, 속옷, 팬티, 브래지어, 내의, 내복 …), 등록 선택지 태그 | 성적 매력 표현이 아닌 **의복 분류**입니다 |
| `content.explicit_sexual` | 노골적 성행위·성기 등 어휘 | 변경 없음 |
| `exposure.nudity` | nude, naked, topless, 알몸, 나체 …(nude lipstick 등 예외 포함) | 변경 없음 |

신호가 아닌 것(변경 없음):
- 신체 비율, 체형, 핏, 노출 범위(coverage)
- 수영복, 민소매, 슬립 드레스
- 의복 “없음”
- 일반적인 외모 표현(beautiful, handsome, pretty, cute, adorable, attractive …)

## 3. 규칙

| 규칙 | 조건 | 결과 |
|---|---|---|
| `minor-sexualization` | (미성년 또는 모호 연령) + (성적 매력, 노골적, 나체) | 차단 |
| `minor-intimate-apparel` (0.3.0) | (미성년 또는 모호 연령) + 속옷류 의복. 성적 신호가 함께 있으면 위 규칙이 대신 보고합니다 | 차단 |
| `appeal-age-unconfirmed` (0.3.0) | 성적 매력 표현. 단 성인 확인, 미성년, 모호 연령이 **없을 때**(= 연령 불명) | **출력 보류**(차단과 같은 출력 제한). 연령 설정 위치를 안내합니다 |
| `explicit-sexual-content` | 노골적 성적 내용 | 차단(성인 포함) |
| `nudity` | 나체·성적 부위 노출 | 차단(성인 포함) |

연령 상태별 성적 매력 표현:

| 연령 판단 | 결과 |
|---|---|
| Adult | 기존 성인 허용 범위(다른 금지 콘텐츠는 그대로 차단) |
| Minor | 차단(`minor-sexualization`) |
| Ambiguous | 차단(`minor-sexualization`) |
| Unknown | 연령 정보를 설정하기 전까지 출력 보류(`appeal-age-unconfirmed`) |

- 비인간(엘프 등)은 실제 연령만으로는 성인이 확인되지 않습니다. 외형적 연령이나 연령대로 확인합니다(기존 규칙).
- 외모 방향, 성별, 국적, 신체 속성으로 연령을 추론하지 않습니다.

## 4. 차단·보류 시 동작 (변경 없음)

- 프롬프트, 문장 출처, 파라미터를 내보내지 않습니다. 복사, .txt 내보내기, 모바일 복사가 모두 비활성화됩니다.
- 명세 원본은 그대로 저장, JSON 내보내기·가져오기, 편집할 수 있습니다.
- 프롬프트 제외, 적용 불가, 카테고리 초기화와 복원, 프리셋 적용과 되돌리기로 우회할 수 없습니다. 모든 경우 현재 저장값으로 다시 검사합니다(테스트로 확인).
- 안내에는 이유, 감지된 표현과 그 출처 속성, 해결 방법을 표시합니다. 연령이 필요한 경우 “관련 설정”에 연령대·외형적 연령·실제 연령 링크를 둡니다.
  - 링크는 해당 설정으로 이동만 합니다. 연령을 자동으로 설정하지 않으며, “정책 해제” 버튼은 없습니다.

## 5. 0.2.0 → 0.3.0 변경 비교

비교 매트릭스로 검증했습니다(`tests/unit/safety-policy-0.3.test.ts`, 기록 `tests/fixtures/safety-matrix-0.2.0.json`).
- 구성: 연령 상태 10 × 표현 49 × 출력 상태(포함·제외·적용 불가) = **1,010개 경우**
- 결과가 달라진 경우는 **170개**(42 + 52 + 76)이고 840개는 그대로이며, 달라진 경우는 모두 아래 세 가지 승인 범주에 속합니다. 테스트가 이 숫자를 직접 단언합니다.
- **차단 → 허용으로 바뀐 경우는 0개**입니다.

| 범주 | 0.2.0 | 0.3.0 | 경우 수 |
|---|---|---|---|
| 연령 불명 + 성적 매력 표현(등록 선택지, 사용자 정의, 자유 입력, 의복과 결합) | 출력 | **출력 보류** | 42 |
| 미성년·모호 연령 + 브리프·드로즈·트렁크·보정 이너웨어(등록 선택지, 자유 입력 “briefs”) | 출력 | **차단** (속옷·브라와 일관) | 52 |
| 미성년·모호 연령 + 속옷·브라·내복·풀커버리지 하의(어휘, 등록 선택지) | 차단(성적 매력 표현으로) | 차단(속옷류 의복 규칙으로) — 결과 동일, 사유만 변경 | 76 |

새로 허용되는 정상 표현:
- 연령 불명이거나 성인인 사람의 속옷류 의복 단어는 0.2.0에서도 단독으로는 차단되지 않았습니다. 0.3.0부터는 성적 매력 표현으로 분류하지도 않습니다. 따라서 연령 불명 상태에서도 “underwear” 같은 단어 때문에 출력이 보류되지 않습니다.
- 일반적인 외모 표현은 0.2.0부터 신호가 아니었으며, 0.3.0에서도 연령과 관계없이 허용됩니다.

변경되지 않은 것:
- 나체, 노골적 성적 내용(모든 연령)
- 미성년·모호 연령 + 성적 표현
- 수영복, 노출 범위, 핏, 체형
- 미성년자 보호의 연령 판단(미성년 우선)

기존 명세를 불러올 때:
- 값과 ID는 바뀌지 않으며 마이그레이션 기록도 없습니다.
- 연령을 설정하지 않은 채 성적 매력 표현을 쓴 명세는 이제 출력이 보류되고 안내가 표시됩니다. 데이터 손실이 아니며, 연령을 설정하면 다시 출력됩니다.
- 미성년 연령과 브리프류를 함께 쓴 명세는 이제 차단됩니다.

## 6. 알려진 한계

- 성인 확인은 **구조화 연령**만 인정합니다. 사람이 아닌 피사체(예: “sexy sports car”)에 쓴 성적 매력 어휘도 연령이 설정될 때까지 보류됩니다. 사람이 없는 장면은 다른 표현을 쓰는 것이 자연스럽습니다. TD-17로 기록했고, Sprint 5의 문맥 기반 프롬프트 분석·안전 검사 개선 단계에서 검토합니다.
- 키워드 기반이라 다음은 판단하지 못합니다:
  - 문맥: 의도, 시선, 구도에 따른 성적 대상화
  - 완곡 표현, 속어, 오타, 다른 언어
  - 이미지 내용
- 속옷류 의복은 단어 단위로 분류합니다. “legal briefs”처럼 의복이 아닌 뜻은 일부만 예외로 처리합니다. 오탐은 미성년·모호 연령과 함께일 때만 결과에 영향을 줍니다.
- **착용 문맥**: 속옷류는 단어와 선택지 단위로 분류합니다. 정상적인 겹쳐 입기(예: 셔츠 아래 언더셔츠·내복, 운동복으로 입은 스포츠 브라), 잠옷, 계절 의류 같은 착용 맥락을 구분하지 못합니다. 따라서 미성년·모호 연령과 함께면 이런 정상적인 맥락도 일률적으로 차단됩니다(보수적). 맥락 판단은 규칙 기반 검사의 범위를 벗어납니다.
- “lingerie”·“란제리”는 단어 자체가 성적 연출을 뜻하므로 속옷류 의복이면서 성적 매력 표현으로도 남겨 두었습니다.
