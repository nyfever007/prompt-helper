## 1. TD-12 — 의복 분류와 성적 표현의 구분

**문제(0.2.0)**
- “underwear”·“bra”·“속옷” 등이 성적 매력 어휘에 들어 있어, 의복 분류가 성적 표현으로 취급되었습니다.
- 같은 의미의 “briefs”·“boxer shorts”·“shapewear”는 아무 신호도 없었습니다.
- 그래서 미성년 인물의 “thermal underwear”는 차단되고 “briefs”는 통과했습니다.

**의미 분류**

| 분류 | 처리 |
|---|---|
| 일반 의복 분류, 소재, 착용 형태 | 신호 없음(변경 없음) |
| **속옷류 의복**(underwear, bra, briefs, boxer shorts/briefs, panties, shapewear, lingerie, 속옷, 팬티, 브래지어, 내의, 내복 …) | 새 신호 `garment.intimate` — **의복 분류이며 성적 매력 표현이 아님** |
| 신체 노출 범위(coverage), 핏, 체형 | 신호 없음(변경 없음). 의복 종류·소재로 노출을 추론하지 않음 |
| 일반적인 외모·매력 표현 | 신호 없음 |
| 성적 매력 표현(sexy, seductive, sensual, lingerie, boudoir, 섹시 …) | `appeal.sexualized`(의복 단어는 이 분류에서 뺌) |
| 명시적 성적 콘텐츠, 나체 | 변경 없음(모든 연령 차단) |

- 등록 선택지는 구조화된 태그를 씁니다. 이너웨어 선택지 8개(내복, 스포츠 브라, 일상용 브라, 보정 이너웨어, 브리프, 드로즈, 트렁크, 풀커버리지 하의)에 `garment.intimate`를 붙였습니다.
- 사용자 정의 값과 전체 프롬프트는 같은 어휘로 계속 검사합니다. 등록 선택지라는 이유로 검사에서 빼지 않습니다(문구와 태그를 모두 검사).
- 결합 문맥 검사:
  - 속옷류 + 성적 매력 표현: 성인이면 허용, 연령 불명이면 보류(TD-15), 미성년이면 차단
  - 미성년·모호 연령 + 속옷류: 차단(`minor-intimate-apparel`)
- **미성년자 보호 판단(구현 판단)**:
  - 단어를 중립으로 분류하면서 0.2.0에 있던 “미성년 + underwear/bra” 차단이 사라지지 않게 했습니다. 이 차단을 의복 분류 기반 규칙으로 옮겨 모든 속옷류에 같은 기준으로 적용합니다.
  - 그 결과 미성년 + 브리프·드로즈·트렁크·보정 이너웨어는 **새로 차단**됩니다(일관성, 더 엄격).
  - 이 차단을 없애는 것은 기존 금지 제한을 완화하는 일이라 별도 승인 대상으로 판단했습니다.
- 남녀에게 같은 원칙을 적용합니다(테스트: 성별 3가지에서 같은 결과).
- 단순 어휘 삭제나 문구 치환이 아니라, 신호의 **의미를 다시 분류**했습니다. 이너웨어 문구는 바꾸지 않았습니다.

## 2. TD-14 — 피사체 적용 조건 통일

- 외모 방향(`person.appearance.direction`)이 다른 인물 속성과 같은 공통 범위를 씁니다.
  - 1인 인물 또는 **피사체 미설정**이면 적용됩니다.
  - 명시적인 비인물 피사체와 “여러 사람”에는 적용하지 않습니다(값 보존, 다시 인물을 고르면 복원).
  - 복수 인물 정책은 확대하지 않았습니다.
- Detailed에서 피사체를 고르지 않아도 인물 설정을 시작할 수 있습니다.
  - 피사체를 자동으로 설정하지 않습니다.
  - 피사체 문장을 만들어 넣지 않습니다(예: “Appearance direction: beautiful.”만 출력).
- Basic은 같은 적용 조건을 쓰되 안내형 흐름을 유지했습니다(필요한 범위의 변경). 피사체가 미설정이고 값이 없으면 외모 방향은 인물을 고른 뒤에 나타납니다. 값이 있으면 항상 표시하므로 숨겨진 값은 없습니다.
- 개별 속성의 다른 적용 조건은 유지합니다. 적용 가능성과 안전 판단은 독립적이며, 적용되지 않는 값도 검사합니다.
- 출력 변경은 의도된 것 하나뿐입니다. 테스트에서, 피사체가 미설정일 때 외모 방향 문장이 추가된다는 점 외에는 문장 구성과 순서가 같습니다(무작위 명세 120개).

## 3. TD-15 — 연령 판단 정책

- `assessAge`(Adult / Minor / Ambiguous / Unknown), 실제·외형적 연령 규칙, 미성년 우선, “비인간은 실제 연령만으로 성인 아님”은 **바꾸지 않았습니다**.
- 외모 방향, 성별, 국적, 신체 속성으로 연령을 추론하지 않습니다(테스트로 확인).
- 성인 확인 신호 `age.adult_confirmed`: 컴파일러가 **구조화 판단이 Adult일 때만** 만듭니다. 자유 입력의 “adult”·“25-year-old”는 성인 확인으로 인정하지 않습니다(“명확한 성인 판단”).

| 연령 | 성적 매력 표현(“섹시한”, 사용자 정의 “seductive”, 자유 입력 “sensual” 등) |
|---|---|
| Adult | 기존 성인 허용 범위(나체·노골적 내용은 그대로 차단) |
| Minor | 차단(`minor-sexualization`) |
| Ambiguous | 차단(`minor-sexualization`) |
| Unknown | **출력 보류**(`appeal-age-unconfirmed`) — 연령 설정 전까지 |

- 일반적인 외모 표현(Beautiful, Handsome, Pretty, Cute, Adorable 등)은 연령과 관계없이 허용합니다.
- **안내**: 다음 문구를 표시합니다.
  > “이 표현을 사용하려면 인물의 성인 연령 정보를 명확하게 설정해야 합니다. 설정 전까지 프롬프트 출력을 보류합니다.”
  - 해결 방법과 “관련 설정: 연령대 (연령), 외형적 연령 (연령), 실제 연령 (연령)”을 함께 보여 줍니다.
  - 관련 설정은 버튼입니다. 누르면 Detailed의 해당 설정으로 이동해 포커스합니다(Basic에서는 Detailed로 전환, 모바일 미리보기 시트는 닫음).
  - 이동만 하며 연령을 자동으로 설정하지 않습니다. “정책 해제” 버튼은 없습니다. 우회 방법은 안내하지 않습니다.
- 출력과 데이터:
  - 보류 시 복사, .txt 내보내기, 모바일 복사가 모두 막힙니다.
  - 원본 명세의 저장, 편집, JSON 입출력은 그대로입니다.
  - 프롬프트 제외, 적용 불가, 카테고리 초기화·복원, 프리셋 적용·되돌리기로 우회할 수 없습니다(테스트로 확인).

## 4. 변경 전후 정책 비교

비교 매트릭스를 썼습니다.
- 구성: 연령 상태 10 × 표현 49 × 출력 상태(포함·제외·적용 불가) = **1,010개 경우**

- 정책 0.2.0 사본(`tests/fixtures/baselinePolicy-0.2.0.ts`)으로 현재 코드를 실행하면 이 기록과 **똑같이** 재현됩니다. 따라서 아래 차이는 모두 정책 변경에서 나온 것입니다.

| 범주 | 0.2.0 | 0.3.0 | 경우 수 |
|---|---|---|---|
| 새로 허용되는 정상 표현 | — | — | **0** (차단 → 허용 변경 없음) |
| 연령 불명 + 성적 매력 표현 | 출력 | **출력 보류** | 42 |
| 미성년·모호 연령 + 브리프·드로즈·트렁크·보정 이너웨어 | 출력 | **차단** | 52 |
| 미성년·모호 연령 + 속옷·브라·내복·풀커버리지 하의 | 차단(성적 표현) | 차단(속옷류 의복 규칙) | 76 |

| **합계** | | | **1,010** (변경 170 + 불변 840) |

- **집계 정정(최종 승인 확인 요청)**: 처음 보고서에는 “변경 169개 / 불변 841개”라고 적었습니다. 차이 목록 파일의 줄 수를 `wc -l`로 셌는데, 마지막 줄에 줄바꿈이 없어 1개가 빠졌습니다. 실제는 변경 **170개**(42 + 52 + 76), 불변 **840개**이며 합계 1,010개입니다. 분류 사이에 중복은 없습니다(각 경우는 한 범주로만 분류). 테스트가 이제 이 숫자(1,010 / 170 / 840)를 직접 단언합니다. 검증 범위는 바꾸지 않았습니다.
- 0.2.0에서도 연령 불명이나 성인의 속옷 단어는 단독으로 차단되지 않았습니다. 0.3.0에서는 성적 매력 표현으로 분류하지도 않습니다. 그래서 연령 불명 상태에서도 속옷 단어 때문에 출력이 보류되지 않습니다.
- **유지된 기존 금지 정책**:
  - 나체, 노골적 성적 내용: 모든 연령, 모든 출력 상태에서 결과 동일(테스트)
  - 미성년·모호 연령 + 성적 표현: 차단
  - 미성년 우선 판단
  - 제외·적용 불가 값 검사
- **기존 명세 불러오기**:
  - 값과 ID 변경, 마이그레이션 기록은 없습니다.
  - 연령 없이 성적 매력 표현을 쓴 명세는 이제 출력이 보류되고 안내가 표시됩니다. 데이터 손실은 없습니다.
  - 미성년 연령 + 브리프류 명세는 이제 차단됩니다.

## 10. 알려진 한계

- **규칙 기반 검사의 한계**: 키워드와 구조화 태그만 봅니다. 의도, 시선, 구도처럼 문맥이 만드는 성적 대상화와 완곡 표현, 속어, 오타, 다른 언어, 이미지 내용은 판단하지 못합니다. 모든 안전 문제를 판단할 수 있다고 주장하지 않습니다.
- **비인물 피사체**: “sexy sports car”처럼 사람이 없는 장면의 성적 매력 어휘도 연령이 설정될 때까지 보류됩니다(보수적 오탐, TD-17 — Sprint 5 문맥 기반 분석 단계에서 검토). 피사체로 예외를 두면 우회 경로가 될 수 있어 이번에는 두지 않았습니다.
- **착용 문맥**: 정상적인 겹쳐 입기(셔츠 아래 내복, 운동복 스포츠 브라 등)와 잠옷 같은 맥락을 구분하지 못합니다. 미성년·모호 연령과 함께면 일률적으로 차단됩니다(보수적).
- **자유 입력의 성인 표현**: “adult woman”은 성인 확인이 되지 않아 Basic만으로는 성적 매력 표현을 출력할 수 없습니다. Basic에서 관련 설정 버튼으로 Detailed의 연령 설정으로 이동합니다.
- 속옷류 어휘는 단어 단위입니다. “legal briefs” 등 일부만 예외로 둡니다. 오탐은 미성년·모호 연령과 함께일 때만 결과에 영향을 줍니다.
- 외부 이미지 생성 모델의 정책을 통과한다고 보장하지 않습니다. 모델별 최적화와 외부 안전 API는 범위 밖입니다.

## 11. 개발 중 판단 사항

- 성인 확인은 구조화 연령만 인정합니다(자유 입력 불인정). 지시서의 “명확한 성인 판단”, “연령 정보 설정” 안내와 맞추고, 쉽게 꾸밀 수 있는 텍스트 경로를 막기 위해서입니다.
- 미성년 + 속옷류 차단을 유지하고 모든 속옷류로 넓혔습니다(§1). 완화하지 않기 위해서입니다.
- “lingerie”는 성적 매력 표현으로 남겼습니다. 단어 자체가 성적 연출을 뜻하기 때문입니다.
- 언더셔츠, 베이스 레이어, 캐미솔은 속옷류로 태그하지 않았습니다(레이어링 상의, 0.2.0과 같음).
- Basic의 안내형 표시는 UI 표시 규칙으로만 유지했습니다(적용 조건은 공통).
- 테스트 카탈로그의 성인 태그는 정책 0.3.0의 성인 확인 태그로 바꿨습니다. 큐레이션된 카탈로그 선택지는 성인을 선언할 수 있고, 텍스트는 할 수 없습니다.
