**TD-13 — 색상 선택**
- 기본 상태에서는 현재 색 견본과 이름(또는 사용자 정의 값, “미설정”), “색상 선택/변경” 버튼, 색마다 선택 해제 버튼만 보입니다.
- 팔레트는 비모달 패널로 열립니다:
  - 단일 선택은 고르면 닫히고 포커스가 버튼으로 돌아갑니다. 화살표 키로 둘러보는 동안에는 열려 있습니다.
  - Escape를 누르거나 바깥을 클릭하면 닫힙니다.
  - 다중 선택은 “완료”를 누를 때까지 열려 있습니다.
- 닫혀 있는 동안에는 팔레트를 렌더링하지 않습니다(DOM 감소).
- 값·ID·출력·저장 형식은 그대로입니다. RGB/HEX 입력은 Sprint 3(TD-05)입니다.

**TD-01 — 카테고리 트리**
- 트리 전체가 Tab 정지점 하나입니다.
- 키: ↑↓, →(펼침 / 하위로), ←(접기 / 상위로), Home·End, Enter·Space.
- 상태 전달:
  - 현재 페이지: `aria-current`·`aria-selected`
  - 펼침: `aria-expanded`, 깊이: `aria-level`
  - 접근 가능한 이름은 라벨만 사용(`aria-labelledby`)
  - 설정 수·경고·차단·설계 중 상태는 접근 가능한 설명(`aria-describedby`)
- 검색 결과 수는 `role="status"`로 안내합니다.
- 입력 문자로 이동(type-ahead)은 넣지 않았습니다.

**TD-02 — 대화상자**
- 초기 포커스는 “취소”이고, Tab은 대화상자 안에서 순환하며, 나머지 화면은 `inert`가 됩니다.
- Escape로 닫고, 닫으면 포커스가 연 버튼으로 돌아갑니다. 초기화한 뒤 연 버튼이 비활성화되면 “카테고리 초기화 되돌리기” 버튼으로 갑니다.
- 비모달 패널은 포커스를 가두지 않습니다:
  - 색상 팔레트는 Escape로 닫으면 포커스가 버튼으로 돌아갑니다.
  - 모바일 미리보기 시트는 열면 제목으로 포커스가 가고, Escape로 닫으면 툴바 버튼으로 돌아갑니다.
- 라이브러리는 추가하지 않았습니다. 네이티브 `<dialog>`는 jsdom에 `showModal`이 없어 쓰지 않았습니다(테스트가 실제 경로를 검증할 수 없음).

## 5. Sprint 2-D 확장 관련 결정 (지시서 §6)

- 현재 선택지 렌더링은 이미 다음을 지원합니다:
  - 텍스트(칩·목록·드롭다운)

- 색상은 팔레트를 연 뒤 선택합니다.
- 접기/펼치기 테스트는 aria-expanded로 검증합니다.
- 버전 기대값을 0.10.0으로, 테스트 확장 카탈로그를 0.11.0으로 바꿨습니다.

## 8. 남은 문제

- **미검증 — 실제 스크린 리더(VoiceOver·NVDA)**: 이 환경에서는 수행할 수 없었습니다. 역할·이름·설명·포커스·키 동작은 jsdom과 Playwright Chromium 자동화로만 검증했습니다. Sprint 2-C.4 통합 검증 항목입니다(TD-16).
- **미검증 — 다크 모드 화면**: 새 스타일은 기존 색상 토큰을 사용합니다(사용자 정의 색을 나타내는 장식용 무지개 견본만 고정 색). Sprint 2-C.4 항목입니다(TD-16).
- 키보드 문자 입력 기반 탐색(type-ahead)은 이번 완료 조건에 포함하지 않습니다.
- 속성 단위로 적용되지 않는 색상(예: 림 라이트 “없음”일 때의 림 라이트 색상)은 접힌 값에 표시하지 않고, 기존 필드 안내로만 알립니다.
- 모달이 열려 있는 동안 새로 생긴 배경 요소(예: 새 알림)는 `inert`가 아닙니다. Tab 순환은 유지됩니다.
- 검색형 목록(44개 속성)은 기존 260px 스크롤 목록 그대로입니다(이번 범위 밖).
